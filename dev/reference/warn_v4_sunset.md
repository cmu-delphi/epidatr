# Warn that a V4 endpoint is being phased out in favor of the V5 API

Warn that a V4 endpoint is being phased out in favor of the V5 API

## Usage

``` r
warn_v4_sunset(fn_name)
```

## Arguments

- fn_name:

  string. Name of the calling function, used to throttle the warning and
  to point users at the right place in the migration guide.
