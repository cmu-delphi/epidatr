# Check for warnings for the cache

Adds warnings when arguments are potentially too recent to use with the
cache.

## Usage

``` r
check_for_cache_warnings(epidata_call, fetch_args)
```

## Arguments

- epidata_call:

  the `epidata_call` object

- fetch_args:

  the args list for fetch as generated by
  [`fetch_args_list()`](https://cmu-delphi.github.io/epidatr/dev/reference/fetch_args_list.md)
