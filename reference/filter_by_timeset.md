# Filter a data frame by a timeset (vector of dates/epiweeks or EpiRange)

Filter a data frame by a timeset (vector of dates/epiweeks or EpiRange)

## Usage

``` r
filter_by_timeset(df, column, timeset)
```

## Arguments

- df:

  data frame to filter

- column:

  name of the column containing time values

- timeset:

  the timeset to filter by
