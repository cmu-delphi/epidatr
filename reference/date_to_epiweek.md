# Converts a date (integer or character) to an epiweek

Converts a date (integer or character) to an epiweek

## Usage

``` r
date_to_epiweek(value)
```

## Arguments

- value:

  date (integer or character, with format YYYYMMDD) to be converted to
  an epiweek

## Value

an integer representing an epiweek, in the format YYYYWW
