# parse_api_week converts an integer to a date

parse_api_week converts an integer to a date

## Usage

``` r
parse_api_week(value, reference_week_day = 1)
```

## Arguments

- value:

  value to be converted to an epiweek

- reference_week_day:

  the day of the week to use as the reference day. Defaults to Sunday.

## Value

a date
